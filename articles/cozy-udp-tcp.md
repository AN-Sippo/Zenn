## 朝食にて

アンズ
「あ！　もう卵ないじゃないですか！」

ぼく
「え？」

アンズ
「卵ですよ！　毎日朝ごはんに卵焼きを食べるのが楽しみだったのに……」

アンズちゃんは、時折こうしてぼくの家に朝食を作りに来てくれるが、今日はどうやら卵をきらしてしまっていたようだ。

ぼく
「ごめん。買い忘れてた」

アンズ
「じゃあ、そこの食パン焼いてあげるので、待っててください。　……彩りがないとか文句言わないでくださいよ？」

ぼく
「いわないよ」

買い忘れてたこちらが悪いのだから、文句など出てくるはずもない。
しかしアンズちゃんが普段よりも、ほんのり不機嫌そうに見えるのは気のせいだろうか。

## 「送ってみてもいいですか？」

食パンが焼けるまでの数分、アンズちゃんはリビングの隅で自分のノートパソコンを開いていた。さっきまでの不機嫌はどこへやら、画面をのぞき込む横顔がやけに楽しそうだ。この子は、こうなると長い。

アンズ
「せんぱい、ちょっと私のパソコンからメッセージ送ってみてもいいですか？」

ぼく
「いいけど。メール？」

アンズ
「UDPです」

メッセージってそういうことか。
LINEなどのサービスでも、HTTPでもなく、UDP。

ぼく
「……なんで」

アンズ
「昨日ソケット触ってたら楽しくなっちゃって」

まったく理由になっていない。が、機嫌が直ったのならそれでいい。ぼくは言われるままにターミナルを開いて、指定されたポートで待ち受けるだけの短いスクリプトを走らせた。届いたものを、届いた順に、そのまま出力する。それだけのループだ。

アンズ
「じゃあ送りますね。……あ、それと」

ぼく
「うん」

アンズ
「今から送ったもの、買ってきてくださいね」

ぼく
「なんだろう。いま、おつかいを押しつけられた気がする」

アンズ
「気のせいですよ」

## おつかい

ぽん、と間の抜けた調子で、ターミナルに一文字だけ現れた。

```
ご
```

ぼく
「ご？」

アンズ
「一文字ずつ、別々に送ってます」

なるほど、と思っているうちに、次が来た。

```
ご
ま
```

ごま。

三文字目を待ってみたが、いつまでも来なかった。台所からは、電子レンジの回る低い音がしている。

なぜ、突然ごまが必要になったのだろう。
不思議に思ったが、あの子のことだから何か考えがあるのだろうと思い直し、ぼくは財布を持って家を出た。

スーパーの棚の前で、すりごまといりごまのどちらかで五分ほど迷い、結局どちらも買った。

## ただいま

帰ってきて袋を差し出すと、アンズちゃんの目がぱっと輝いて、それから一秒もかからずに、すうっと温度を失った。

アンズ
「……なんですか、これ」

ぼく
「ごま」

アンズ
「ごま」

ぼく
「すりといり、両方買ってきた」

アンズちゃんは袋を受け取らないまま、ぼくの肩ごしにターミナルを覗き込んだ。ぼくもつられて振り返る。

出しっぱなしの画面には、二行しか並んでいなかった。

```
ご
ま
```

アンズ
「あ」

アンズちゃんは黙って自分のノートパソコンをこっちに向ける。

```
送信: た ま ご
```

ぼく
「……たまご、か」

アンズちゃんは袋を両手で受け取って、うつむいた。

アンズ
「順番、保証されないんですよ。届くことも、届く順番も、何も。それがUDPなので」

ぼく
「いい話風にまとめないで」

アンズ
「……レンジ、回してましたよね。電子レンジは電波に干渉するんですよ」

ぼく
「回してたのは君だよ」

アンズ
「そうでした」

ごまの袋を抱えたまま、アンズちゃんはしばらく黙っていた。

アンズ
「次はTCPで送ります。あれなら順番も到達も保証されるので」

ぼく
「うん」

アンズ
「……普通に口で言えばよくないですか？」

ぼく
「それ、ぼくのセリフだよ」

焼き上がった食パンは、待たされたぶんすっかり冷めていた。バターだけの、たしかに彩りのない朝ごはんだった。

アンズ
「明日は、ごま入りの卵焼きにしてあげます」

ぼく
「豪華だ」

アンズ
「なので、たまご、買っといてくださいね」

ぼく
「今度はちゃんと口で言われた」
