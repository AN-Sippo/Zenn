## ある日

アンズ
「せんぱい、私のプリン知りませんか？」

ぼく
「……あ、ごめん。これアンズちゃんのやつか」

ぼくは手に持っていたスプーンをテーブルに置くと、すでにひと口ほどしか残っていない**それ**が乗ったお皿を差し出す。

ぼく
「よかったら、残り食べる……？」

アンズ
「要らないです！　というかもうほとんど残ってないじゃないですか！」

ぼく
「ごめんなさい」

アンズちゃんは大学の後輩で、授業が終わるとこうしてぼくの家に遊びに来ることが多い。
だからおやつも、うちの冷蔵庫に保管していたのだろうが、ぼくが気づかずに食べてしまったのだった。

アンズ
「せんぱいはなんで人のものを勝手に……。もういいです。私が予約システムつくりますから」

ぼく
「予約しすてむ？」

またアンズちゃんの発明スイッチを入れてしまったらしい。

## プリン予約システム

その日の夜には、冷蔵庫の扉に見慣れないQRコードが貼られていた。

アンズ
「プリンとアイスを買ってきたら、この管理画面から個数を登録してください」

スマートフォンで読み込むと、画面には「プリン」と「バニラアイス」が並び、その横に数字を入力する欄があった。

ぼく
「冷蔵庫に2個入れたら、ここにも2個、と」

アンズ
「はい。それで、毎日13時を過ぎたら、その日に食べる分を予約できます。予約した人だけが食べていいんです」

ぼく
「そこまでしないと、ぼくは信用されないのか」

アンズ
「されると思ってたんですか？　私のプリンを食べたのに？」

怒りはまだ収まっていないようだ。

翌日から、ぼくらは律儀に予約システムを使った。

13時になると予約ボタンが押せるようになり、誰かが予約するたびに在庫が1つ減る。在庫がゼロなら失敗と表示される。単純な仕組みだけれど、効果は絶大だった。

少なくとも、しばらくのあいだは。

## 最後のひとつ

ある日の13時すぎ、講義を終えたぼくは予約画面を開いた。

```
プリン　残数：1
```

予約ボタンを押す。

```
予約成功　残数：0
```

最後の1個を取れたことが、なんとなく嬉しかった。

家に帰ると、ぼくは冷蔵庫からプリンを取り出した。誰にも後ろめたくないプリンは、いつもより少しだけおいしい。

半分ほど食べたところで、玄関の扉が勢いよく開いた。

アンズ
「せんぱい！　それ、私が予約したやつなんですけど！」

ぼく
「え。いや、今日はちゃんと予約したよ」

アンズ
「私もしました！」

アンズちゃんは靴を脱ぐのもそこそこに、スマートフォンを突き出してきた。

```
予約成功　残数：0
```

ぼくも自分の画面を見せる。

```
予約成功　残数：0
```

同じ成功画面が、2つ並んだ。

アンズ
「……ちょっと待ってください」

アンズちゃんはテーブルにノートパソコンを広げ、ログを追い始めた。指の動きがだんだん遅くなって、やがて止まる。

小さく「あ」と声が漏れた。

画面には、こんな記録が残っていた。

```
アンズ：残数を読む → 1
ぼく　：残数を読む → 1
アンズ：予約成功と判定する
ぼく　：予約成功と判定する
アンズ：残数を0に更新する
ぼく　：残数を0に更新する
```

ぼく
「2人とも、1個あるのを見たんだ」

アンズ
「……残数を確認してから更新するまでが、別々の処理になってて。その隙間に、せんぱいのリクエストが––」

だんだん声が小さくなっていく。

アンズ
「……私が書いたコードです」

ぼく
「うん」

アンズ
「言わないでください」

ぼく
「まだ何も言ってない」

アンズ
「TOCTOU。こんなミスをするなんて……」

ぼく
「とくとう？」

アンズ
「**T**ime **O**f **C**heck to **T**ime **O**f **U**se。確認から使用までの間に、状態が変わっていることで生じるバグのことです」

ぼく
「そんな名前がついてるんだ」

アンズ
「そっか。せんぱいが残数を読んでから更新するまでと、私が残数を読んでから更新するまで。この2つを、Isolationしないといけないんだ」

ぼく
「あい、それーしょん？」

アンズ
「途中に割り込めない、互いに排他的な操作にするってことです。……あの、今恥ずかしいのであんまり解説させないでもらえますか？」

言いながら、アンズちゃんはもうキーボードを叩き始めていた。立ち直りが早い。

アンズ
「在庫を確認して、成功失敗の判定・在庫を1つ減らす。この処理をどちらかが行っている間、もう1人は同じ処理を行うことができないようにします」

ぼく
「つまり、最後の1個を取れるのは1人だけ」

アンズ
「最初からそうなるはずだったんです！」

## もう1度

翌日、ぼくらは残数を1にして、同時に予約ボタンを押した。

ぼくの画面には、

```
予約失敗　残数：0
```

アンズちゃんの画面には、

```
予約成功　残数：0
```

と表示された。

アンズ
「今度こそ私のですからね」

ぼく
「わかってるよ」

アンズちゃんは満足そうにプリンを取り出した。それから、冷蔵庫の奥にもう1つ入っているのを見つけて、首をかしげる。

アンズ
「これ、在庫に登録されてませんけど」

ぼく
「昨日のぶんのお詫び。アンズちゃんに」

アンズ
「……私、1日に2個も食べられません」

ぼく
「明日に取っておけば？」

アンズちゃんは少しだけ笑って、管理画面の個数を1つ増やした。

アンズ
「じゃあ、また明日勝負ですね？」

ぼく
「……望むところだ」

——翌日

アンズ
「やった予約できた！　……これで2連勝ですね？」
